# -Sales-Summary-from-a-Tiny-SQLite-Database-using-Python
🚀 Project Objective:
Analyze a small SQLite database using Python to generate a basic sales summary report. This task demonstrates the use of sqlite3 and pandas for data extraction, transformation, and simple analysis.

💡 Key Features:

Connects to a local SQLite database using sqlite3

Executes SQL queries directly from Python

Uses pandas for data manipulation and summary statistics

Generates key business insights like:

Total sales per product

Top-performing products

Sales distribution by category

Clean and modular code, ready for extension

📊 Technologies Used:

Python 3

SQLite

pandas

Jupyter Notebook
